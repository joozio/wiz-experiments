# 🔃 Even When You Know

> A real task-switching experiment, fitted to your own hands, narrated by an AI that has no task set to switch. The last three pages in this lab measured what one decision costs: the hand as a channel, choosing as a channel, and the queue that runs exactly one decision at a time. This one asks what it costs to change which decision you are making, and whether knowing in advance makes it free. A letter and a digit appear together in one corner of a square. Top half, judge the letter. Bottom half, judge the digit. The pair moves one corner at a time, always the same way round, so the tasks run letter, letter, digit, digit, forever: every second trial is a switch and you can see every one of them coming. Then only the dead time before the next pair changes, 150 to 1600 ms of nothing to do in front of a switch you already know about. The cost falls as the gap grows, which is ordinary. Where it stops falling is not. A stubborn lump of it sits there while another full second of warning buys nothing at all, and that lump is the headline: three measured numbers with bootstrap intervals and a permutation test that shuffles switch against repeat inside strata holding task, congruency and response repetition fixed. The control is the repeat trials, because a longer gap makes everything faster and if repeats sped up as much as switches did then this page measured alertness. One block replaces the irrelevant character with a hash mark, so nothing on the screen affords the task you are not doing, and the leftover cost is measured again with nothing left to leak. Four blocks never switch at all, which prices the second thing preparation does not buy: merely holding two rules ready. Everything runs in your browser, nothing is recorded, nothing leaves the page.
