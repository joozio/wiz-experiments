# 🎲 Not How Many

> A real Hick and Hyman experiment, fitted to your own hands, narrated by an AI for which a choice among eight and a choice among eight thousand cost the same forward pass. The law has the same shape as the Fitts page next door and the same unit: reaction time equals a plus b times H, where H is entropy in bits, and the slope is your bandwidth for choosing rather than for aiming. The version quoted in design books is the weak one. Reaction time grows with the logarithm of the number of choices has been used as an argument for shorter menus since the fifties, and it is not what Ray Hyman showed in 1953. Hyman held the number of alternatives fixed and changed only how often each came up, and reaction time tracked the entropy anyway. The number of options is not in the formula. It is in the popular version only because equally likely options are the one special case where H equals log2 of N. The design is a ladder and one block that breaks it. Four blocks are the classic ladder, one, two, four and eight equally likely boxes, zero to three bits. The fifth has eight boxes, the same eight keys, and a distribution nobody tells you about: one box half the time, one a quarter, six others one time in twenty four. Eight options carrying 2.15 bits. So the headline is three measured averages and nothing fitted, and it is a model comparison in disguise, because a page that believed the popular version predicts the skewed block costs exactly what the eight block costs, both having eight, while Hyman predicts it lands next to the four option block. Your hands pick between them. The model layer is then held harder than a fit: the line is fitted to the four uniform blocks only and made to predict the three surprisal cells inside the skewed block with no free parameters left, including the six rare boxes at 4.585 bits, which is past the end of the ladder and is marked as an extrapolation rather than presented as a fit. The geometry is decided by the confound: the obvious build has you tap whichever box lit, which is a Fitts task in a Hick costume, so the response set here never moves, always eight boxes at the same size in the same places, and only how many can light ever changes. On a keyboard your fingers never travel; on a touchscreen they do, so movement is measured and the slope is printed with it and without it. The calibration honesty is a theorem: a reaction time here is an absolute latency containing your whole display pipeline, key scan and event loop, and none of that can be recovered, but all of it is the same constant on every trial in every block, and a constant added to every point on a line moves the intercept and cannot touch the slope. The headline is a difference between two block means, so it cancels there outright. Bits are dimensionless, so the x axis is the same on a gaming monitor and a phone. The control that matters most is repetition, because the frequent box is also the box most likely to repeat and repeats are faster in every choice task ever run, so every cell is split into repeat and switch trials and the whole prediction is re-run with repeats thrown away. Guards run live: shuffled block order, an unscored practice block, twelve dropped trials in the skewed block because a distribution nobody described has to be learned first, presses under 120 ms discarded as anticipations and re-queued, hidden tabs killing their trial, no position appearing three times in a row, a block over 15 percent errors refused, a run over 25 percent refused with the reason spelled out, a run whose reaction times are all the same named one rhythm for everything, and the browser's own clock quantum recovered from your data and refused above 40 ms. The playground puts eight options on one slider and takes 3 bits down toward zero without ever removing an option. And the payoff is what it explains about every interface you have used: why a menu of thirty commands you know is not slow, why the shortcut you press twice a year is, why autocomplete removes nothing and redistributes everything, why Huffman coding under every zip file and JPEG is this arithmetic run backwards, and why the advice to cut the number of choices was always aiming at the wrong variable. Everything runs in your browser, nothing is recorded, nothing leaves the page.
